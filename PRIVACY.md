# Privacy Policy for Tweak Header

Last updated: July 14, 2026

Tweak Header does not collect, transmit, sell, or share personal information or browsing data. Header rules and the enabled/paused setting are stored only on the user's device using Chrome's local extension storage.

The extension requires access to websites the user visits solely to apply the HTTP request-header changes explicitly configured by the user. Manifest V3's declarative network request API applies those rules inside Chrome; Tweak Header does not read or retain request bodies, page content, browsing history, or server responses.

Tweak Header does not use analytics, advertising, remote code, or external services.

Users can delete all locally stored data by removing the extension. Questions about this policy may be submitted through the support contact shown on the Chrome Web Store listing.
